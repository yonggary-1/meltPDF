# meltPDF v0.12.0

**새 기능: [이미지 내보내기]가 PDF 쪽 안의 원본 이미지를 꺼내 저장합니다.** 이전에는 PDF 쪽을 건너뛰었습니다.

사용 방법은 그대로입니다. PDF를 [기존 PDF 열기]나 끌어다 놓기로 열면 쪽이 목록에 들어오고, 순서를 바꾸거나 지운 뒤 [이미지 내보내기]를 누르면 목록에 남은 쪽의 이미지가 저장됩니다.

1. **PDF 쪽 안의 이미지 꺼내기** (새 파일 `pdf_images.py`, `image_export.py` 연결): 쪽을 그림으로 그리지 않고, 그 쪽에 쓰인 이미지 자체를 꺼냅니다. JPEG와 JPEG2000은 PDF 안에 든 바이트 그대로(CMYK, 흑백 JPEG 포함), 그 밖의 형식(압축을 푼 픽셀, 흑백 스캔용 압축 등)은 같은 픽셀의 PNG로 나옵니다. 투명 마스크가 붙은 이미지는 마스크를 합쳐 투명 PNG로 저장합니다.
2. **파일 이름:** "PDF이름 - p003.jpg"(3쪽의 이미지). 한 쪽에 이미지가 여러 장이면 그려지는 순서대로 "- p003_1.jpg", "- p003_2.jpg". 파일명 변경하기로 이름을 바꿨다면 그 이름을 씁니다. 저장 순서는 목록 순서입니다. 같은 이미지를 여러 쪽이 쓰면(예: 로고) 처음 나온 쪽에서 한 번만 저장합니다.
3. **건너뛰는 쪽:** 이미지가 없는 쪽(글자만 있는 쪽 등)이나 이미 저장한 이미지뿐인 쪽은 건너뛰고 완료 창에 개수를 알립니다.
4. **하지 않는 것:** 회전·잘라내기 같은 쪽 설정은 반영하지 않습니다(저장된 이미지 그대로). 스캔본은 회전이 쪽 설정에 들어 있는 경우가 있어 옆으로 누워 나올 수 있습니다. 쪽을 그림으로 그려 저장하는 것도 하지 않습니다.
5. **안전장치:** 암호가 필요한 PDF와 내용 복사를 막아 둔 PDF는 이미지를 꺼내지 않고 사유를 알립니다(우회하지 않음). 원본 PDF를 찾을 수 없으면(옮기거나 지움) 그 사유를 알리고 나머지는 저장합니다.

**확인한 것:** Linux 가상 화면(Xvfb)에서 직접 만든 PDF로 확인했습니다.
- JPEG 4쪽 PDF: 저장된 4개가 PDF에 넣은 원본 JPEG와 바이트까지 같음. 흑백 JPEG와 CMYK JPEG도 같음(PyMuPDF의 기본 추출은 CMYK JPEG를 다른 바이트로 돌려주어서, PDF 안의 원본 스트림을 직접 읽도록 했습니다). JPEG2000도 바이트까지 같음.
- PNG(압축 푼 픽셀)는 픽셀이 같은 PNG, 투명 PNG는 투명도까지 픽셀이 같음(PyMuPDF의 합성 방식은 투명한 곳의 색을 잃어서 쓰지 않고 직접 합쳤습니다). 흑백 스캔용 압축(CCITT G4)도 같은 픽셀의 PNG.
- 목록에서 쪽 순서를 바꾸고 일부만 남기면 목록 순서대로, 남은 쪽의 이미지만 저장됨. 한 쪽에 이미지 2장은 `_1`/`_2`, 같은 이미지를 쓴 다른 쪽은 건너뜀, 글자만 있는 쪽은 건너뜀. 이미지 항목과 PDF 쪽이 섞여 이름이 겹치면 " (1)"이 붙음. 파일명 변경 결과가 이름으로 쓰임.
- 복사가 막힌 PDF와 암호 PDF는 거절 안내, 소유자 암호만 있고 복사는 허용된 PDF는 저장됨. 원본 PDF가 없어진 경우 사유 안내 후 오류 없이 끝남.
- 실제 화면(끌어다 놓기): 이미지가 든 쪽 3개와 글자 쪽 1개짜리 PDF를 열고 글자 쪽을 지운 뒤 [이미지 내보내기] -> 한글 폴더 이름 아래에 3개 저장, "PDF 쪽 1개는 건너뛰었습니다" 안내.
- 회귀: epub/fb2, zip, 이름 복원, 이미지 내보내기, 잘린 zip 복구, RAR 직접 받기 시험이 모두 그대로 통과.

**확인하지 못한 것:**
- **실제 PDF:** 직접 만든 PDF로만 확인했습니다. 실제 스캔본/전자책 PDF에서는 한 쪽을 여러 조각으로 쪼갠 이미지, 마스크 조합(배경 JPEG + 글자 마스크) 등이 있어 저장되는 이미지 개수가 쪽 수와 다를 수 있습니다(마스크용 흑백 이미지가 따로 저장될 수 있음).
- 회전 정보 때문에 옆으로 누운 채 저장되는 PDF(위 4번)를 어떻게 다룰지는 정하지 않았습니다.
- **Windows:** 확인하지 못했습니다.
- JBIG2 압축, 인라인 이미지(쪽 안에 직접 들어 있는 작은 이미지)는 시험하지 못했습니다. 인라인 이미지는 꺼내지 않습니다.
- mobi/azw/azw3, djvu는 이번 빌드에 없습니다.

### 받는 방법
이 릴리스의 소스는 위 태그(`v0.12.0`)의 소스 코드입니다. 압축을 풀고 폴더 구조를 그대로 둔 채 `build.bat`을 더블클릭하면 `dist\meltPDF.exe`가 만들어집니다(Python 3.9 이상 필요, 인터넷 필요). 자세한 사용법은 README.md, 전체 변경 이력은 CHANGELOG.md, 외부 소프트웨어 출처는 THIRD_PARTY_NOTICES.md를 보세요.
