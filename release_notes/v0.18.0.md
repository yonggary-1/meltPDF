# meltPDF v0.18.0

**새 기능: 불러오기 속도 개선 (여러 장 동시 처리, JPEG 축소 풀기, 읽는 대로 바로 표시).**

1. **JPEG 축소 풀기** (`pdf_core._make_thumb_bytes`): 목록 썸네일(160px)만 필요한데 원본 전체를 풀던 것을, JPEG는 처음부터 1/2~1/8 크기로 풀도록 바꿨습니다. 원본 크기는 파일 머리에서 읽고, 내보내기는 원본 파일/바이트를 그대로 쓰므로 결과물 화질과는 상관없습니다. 썸네일 차이는 이전과 평균 1단계 미만(0~255 중)입니다. 썸네일 PNG 압축도 빠른 단계로 바꿨습니다.
2. **여러 장 동시 처리** (새 파일 `parallel_load.py`): 썸네일 만들기를 코어 수 - 1개(코어가 2개 이하면 그 수), 최대 8개 스레드로 나눠 합니다. 미리 맡기는 양은 "동시 수 x 2"장까지라 메모리를 많이 쓰지 않고 [중단]에도 금방 멈춥니다. 목록 순서는 넣은 순서 그대로입니다.
3. **읽는 대로 바로 표시** (새 파일 `incremental_add.py`, `doc_model.py`, `tile_view.py`): 다 읽을 때까지 기다리지 않고 24장 또는 0.4초마다(첫 묶음은 0.15초) 목록에 붙입니다. 이미 그린 타일은 두고 새로 붙은 타일만 그립니다.
- 폴더/이미지 파일(`file_loader.py`)과 압축/책 파일에서 꺼낸 이미지(`book_loader.py`) 모두 적용. PDF 쪽 그리기는 예전처럼 한 장씩입니다. 책 파일의 서지 정보는 첫 묶음과 함께 반영됩니다.
4. **[불러오기 중단] 버튼** (새 파일 `load_stop.py`): 이미지가 바로 목록에 들어오므로, 목록이 빈 동안에만 보이는 가운데 [중단]은 금방 사라집니다. 그래서 목록에 이미지가 있는 채로 불러오는 중이면 하단 상태 줄 오른쪽(메모리 표시 왼쪽)에 [불러오기 중단]이 나옵니다. 하는 일은 가운데 [중단]과 같습니다. 압축/책 파일도 이제 중단하면 "불러오기를 중단했습니다. (N장 불러옴)"이 나옵니다.
5. **같이 고친 것**:
   - 흑백(1비트) 이미지의 썸네일이 점무늬로 보이던 것을 회색으로 부드럽게 나오게 했습니다.
   - 16비트 흑백 PNG(스캔본에 있음)가 정상 파일인데 "손상된 이미지"(빨간 테두리)로 잘못 표시되던 버그를 고쳤습니다.

**측정 (A4 300dpi, 같은 파일):**
- 코어 2개 리눅스: JPEG 92 -> 19ms/장(약 4.8배), PNG 275 -> 153ms/장(약 1.8배).
- Wine의 윈도우용 파이썬 3.12: JPEG 107 -> 23~29ms/장, PNG 272 -> 128~137ms/장.

**확인한 것:**
- 순서 유지(폴더 하위 폴더 포함 자연 정렬, cbz), 잘린 JPEG/PNG의 손상 표시, EXIF 회전, CMYK/회색/팔레트+투명/RGBA/LA/16비트/GIF/WebP/BMP/1비트 TIFF의 크기와 썸네일, 같은 이미지들로 PDF 내보내기.
- 읽는 도중 목록에 먼저 나타남, 다 읽은 뒤 타일과 목록이 일치, 상태 줄 "총 N페이지".
- [불러오기 중단]: 목록이 찬 채로 120장 폴더 + cbt를 놓고 중단 -> 읽은 데까지만 남고 뒤 작업 취소, 오류 창 없음, 버튼 사라짐. 끌어서 순서를 바꾼 뒤 이어 붙일 때 타일 위치 일치.
- Wine의 윈도우용 파이썬으로 프로그램 전체 실행 시험(djvu/cb7/cbt, 서지 정보, 복사, 폴더 40장 1초 안에 불러옴, 도중 중단) 통과.
- 기존 회귀 시험 통과(예전부터 맞지 않던 시험 2개는 이번 변경 전 코드에서도 똑같이 실패해 이번 변경과 무관).

**확인하지 못한 것:**
- 실제 Windows, 특히 코어가 많은 PC에서의 체감 속도와 화면 반응.
- 수천 장짜리 폴더를 불러올 때 화면이 매끄러운지.

### 받는 방법
이 릴리스의 소스는 위 태그(`v0.18.0`)의 소스 코드입니다. 압축을 풀고 폴더 구조를 그대로 둔 채 `build.bat`을 더블클릭하면 `dist\meltPDF.exe`가 만들어집니다(Python 3.9 이상 필요, 인터넷 필요). 자세한 사용법은 README.md, 전체 변경 이력은 CHANGELOG.md, 외부 소프트웨어 출처는 THIRD_PARTY_NOTICES.md를 보세요.
