# meltPDF v0.13.0

**새 기능: mobi / azw / azw3(킨들 계열 책)에서 이미지 꺼내기.** 책 안의 이미지만 책에 나오는 순서대로 목록에 넣습니다.

1. **MOBI 읽기** (새 파일 `book_mobi.py`, `book_import.py` 연결): mobi/azw/azw3는 PalmDB 파일 하나에 본문 글 레코드와 이미지 레코드가 이어져 있습니다. 이미지 레코드는 저장된 순서가 읽는 순서와 다른 경우가 많아(변환 도구가 이름순으로 번호를 매김), 본문을 풀어서 이미지를 부르는 자리를 읽는 순서대로 찾습니다. MOBI는 `<img recindex="N">`, AZW3(KF8)는 `kindle:embed:XXXX`(32진수)입니다. 풀 수 있는 본문 압축은 PalmDOC(가장 흔함)과 압축 없음입니다.
2. **표지와 중복:** EXTH에 표지로 지정된 이미지는 쪽에서 쓰지 않아도 맨 앞, 표지 썸네일은 뺍니다. 같은 이미지를 여러 번 부르면 처음 자리에만 넣습니다. 이미지는 재인코딩 없이 레코드 바이트 그대로 꺼냅니다. 이름은 `image_00001.jpg`처럼 붙습니다.
3. **mobi+azw3 합본 파일:** 두 쪽이 같은 이미지 레코드를 쓰므로 MOBI 쪽만 읽습니다.
4. **허프만(HUFF/CDIC) 압축:** 아주 옛 파일에서만 쓰이며 아직 풀지 못합니다. 이 경우 이미지를 파일에 저장된 순서로 넣고 "책 순서와 다를 수 있습니다"라고 알립니다.
5. **안전장치:** 암호화 표시가 있는 파일(DRM)은 열지 않고 사유를 알립니다(우회하지 않음). 이미지가 없는 글 위주 책은 "이미지가 들어 있지 않습니다", 레코드 목록이 잘리거나 mobi가 아닌 파일은 오류로 알립니다. 항목 하나 1GB, 전체 16GB 한도는 zip과 같습니다. 파일 종류는 확장자가 아니라 내용(`BOOKMOBI`)으로 판별하고, 파일 선택 창과 끌어다 놓기에 `.mobi`, `.azw`, `.azw3`가 추가되었습니다. 새 외부 패키지는 쓰지 않았습니다.

**확인한 것:** Linux 가상 화면(Xvfb)에서, calibre(`ebook-convert`)로 만든 시험 파일로 확인했습니다.
- 이미지 12장짜리 만화 책을 mobi, azw3, mobi+azw3 합본으로 변환한 파일 3개에서 모두 12장이 책 순서대로 나옴(이미지 레코드의 저장 순서는 책 순서와 달랐음을 확인). 메모리/디스크 저장 방식 모두 같은 결과. 표지가 맨 앞.
- 글 위주 mobi/azw3는 "이미지가 들어 있지 않습니다". DRM 표시를 넣은 파일은 DRM 안내로 거절. Huffman 압축으로 표시한 파일은 저장된 순서로 나오고 안내가 붙음. 잘린 파일과 mobi가 아닌 파일은 오류 안내.
- 화면: 끌어다 놓기로 azw3, mobi, 글 위주 mobi, DRM mobi를 차례로 넣으면 이미지 24장이 한 목록에 쌓이고, 글 위주 책과 DRM 책은 각각 사유가 경고 창에 나옴.
- 회귀: epub/fb2, zip, 이름 복원, 이미지 내보내기, 잘린 zip 복구, RAR 직접 받기 시험이 모두 그대로 통과.

**확인하지 못한 것:**
- **실제 킨들 책:** 이 환경에는 진짜 mobi/azw 파일이 없고 외부에서 내려받을 수도 없어, calibre가 만든 파일로만 확인했습니다. 아마존이 만든 파일은 구조가 다를 수 있습니다(특히 KF8의 skeleton/fragment 구조에서 이미지가 나오는 순서, 합본 파일의 실제 구조).
- **허프만 압축 해제:** 풀지 않습니다. 직접 만든 표시 파일로 "저장된 순서 + 안내" 동작만 확인했습니다.
- **DRM:** 암호화 표시를 바꾼 파일로만 시험했고, 실제 DRM 책은 없습니다.
- **Windows:** 파일 선택 창 필터와 윈도우 경로는 확인하지 못했습니다.
- azw1(Topaz), kfx(azw8)는 지원하지 않습니다. djvu는 이번 빌드에 없습니다(ROADMAP 다음 순서).

### 받는 방법
이 릴리스의 소스는 위 태그(`v0.13.0`)의 소스 코드입니다. 압축을 풀고 폴더 구조를 그대로 둔 채 `build.bat`을 더블클릭하면 `dist\meltPDF.exe`가 만들어집니다(Python 3.9 이상 필요, 인터넷 필요). 자세한 사용법은 README.md, 전체 변경 이력은 CHANGELOG.md, 외부 소프트웨어 출처는 THIRD_PARTY_NOTICES.md를 보세요.
