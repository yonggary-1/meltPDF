# meltPDF v0.15.0

**새 기능: azw1(Topaz)에서 삽화와 서지 정보 꺼내기.** 킨들의 옛 Topaz 책(.azw1, .tpz, Topaz인 .azw)을 불러올 수 있습니다.

1. **삽화만 꺼냅니다** (새 파일 `book_topaz.py`, `book_import.py` 연결): Topaz는 스캔한 책을 글자 모양(glyph)과 위치로 바꿔 저장한 형식이라 쪽 자체는 이미지가 아닙니다. 쪽을 다시 그리지 않고("파일 안의 원래 이미지를 그대로 꺼낸다"는 원칙), 파일에 이미지로 들어 있는 삽화/표지만 바이트 그대로 꺼냅니다. 같은 번호의 컬러판(color 레코드)이 있으면 컬러판을 씁니다. 압축(zlib)된 이미지는 풀어서 꺼냅니다.
2. **순서와 이름:** 파일에 저장된 이미지 번호 순입니다(쪽 데이터에서 이미지 자리를 찾지 않으므로 책 순서와 다를 수 있습니다). 이름은 `image_00001.jpg` 꼴이고, 확장자는 내용에 맞춥니다. 불러오면 "삽화/표지만 꺼냈다"는 안내가 뜹니다. 이미지가 하나도 없는 책은 "이미지가 들어 있지 않습니다"와 함께 그 이유를 알립니다.
3. **서지 정보:** metadata 레코드의 제목(UpdatedTitle 우선), 저자(여러 명), 출판사, 언어, 설명을 읽어 서지 정보 창과 PDF에 씁니다(v0.14.0 규칙).
4. **안전장치:** 책 열쇠(dkey) 레코드가 있거나 암호화된 레코드가 있으면 DRM이 걸린 책으로 보고 열지 않습니다(우회하지 않음). 끝이 잘린 파일은 남아 있는 이미지만 넣고, 중간에서 끊긴 이미지는 손상 표시(빨간 테두리), 없는 이미지는 사유를 알립니다. 이미지가 아닌 레코드는 빼고 알립니다. 항목 1GB, 전체 16GB 한도는 다른 형식과 같습니다.
5. **판별과 확장자:** 파일 앞부분(`TPZ` + 숫자)으로 판별합니다. 파일 선택 창과 끌어다 놓기에 `.azw1`, `.tpz`를 추가했습니다. `.azw`는 이미 목록에 있고, 내용이 Topaz면 Topaz로 읽습니다.

**확인한 것:** 실제 Topaz 파일이 없어(만들 수 있는 도구도 없음), 알려진 구조대로 직접 만든 시험 파일로 확인했습니다. 시험 파일의 머리 구조와 서지 정보는 calibre에 들어 있는 Topaz 읽기 코드(calibre/ebooks/metadata/topaz.py)로 읽어도 같은 결과가 나오는 것을 확인했습니다(이 calibre 판은 파이썬 3 문자열 문제로 원래 진입점이 Topaz를 못 열어, 같은 코드의 내부 함수로 읽음).
- 이미지 5장 책: 꺼낸 5장이 넣은 원본과 바이트까지 같음(메모리/디스크 방식), 이름 순서, 서지 정보(한글 제목, 저자 2명, 출판사), 안내 문구.
- zlib 압축 이미지, 컬러판이 있는 번호만 컬러판(PNG)으로 바뀜. dkey가 있는 책(.azw 이름)과 암호화된 레코드가 있는 책은 DRM 안내로 거절. 이미지 없는 책은 이유와 함께 안내. 서지 정보가 없는 책은 이미지만. 이미지가 아닌 레코드는 빼고 안내. 반쯤 잘린 파일은 2장 정상 + 1장 손상 표시 + 없는 2장 안내. 머리가 깨진 파일과 아무 바이트나 든 파일은 오류 안내. 가변 길이 숫자의 경계값(0xFF로 시작하는 큰 수, 음수 표시).
- 화면: 끌어다 놓기로 azw1(5장, 서지 정보 들어감), DRM .azw, 이미지 없는 azw1, 잘린 azw1을 차례로 넣어 각각 맞는 안내가 뜨고 손상 표시가 붙음.
- 회귀: 서지 정보, zip/이름 복원/이미지 내보내기/잘린 zip 복구/RAR 직접 받기/epub/fb2/mobi/PDF 이미지 꺼내기 시험이 모두 그대로 통과.

**확인하지 못한 것:**
- **실제 azw1 파일:** 직접 만든 파일로만 시험했습니다. 구조는 calibre와 DeDRM(topazextract)이 쓰는 것을 따랐지만, 실제 파일에서 이미지 레코드가 다른 형식(예: 특수 압축)이거나 서지 정보 키 이름이 다를 수 있습니다. 실제 파일에서 안 열리거나 이미지가 이상하면 알려 주세요.
- 컬러판(color)과 흑백판(img)의 번호가 서로 맞는다는 것은 DeDRM의 동작을 바탕으로 한 가정입니다.
- 쪽 순서대로 정렬하지 않습니다(쪽 데이터 해석이 필요).
- Windows에서는 확인하지 못했습니다.

### 받는 방법
이 릴리스의 소스는 위 태그(`v0.15.0`)의 소스 코드입니다. 압축을 풀고 폴더 구조를 그대로 둔 채 `build.bat`을 더블클릭하면 `dist\meltPDF.exe`가 만들어집니다(Python 3.9 이상 필요, 인터넷 필요). 자세한 사용법은 README.md, 전체 변경 이력은 CHANGELOG.md, 외부 소프트웨어 출처는 THIRD_PARTY_NOTICES.md를 보세요.
