# meltPDF v0.7.0

**rar/cbr이 열리도록 공식 UnRAR를 프로그램에 같이 넣었습니다.** (v0.6.0의 rar 지원은 컴퓨터에 7-Zip/WinRAR/UnRAR 같은 도구가 따로 있어야 열렸는데, 사용자 환경에서 열리지 않았습니다.)

1. **UnRAR를 프로그램 안에 포함:** `tools/UnRAR.exe`를 `build.bat`이 만드는 exe 안에 넣습니다(`--add-data`). 프로그램은 이것을 가장 먼저 쓰므로 7-Zip/WinRAR을 따로 설치하지 않아도 되어야 합니다. 같이 들어 있는 것을 쓸 수 없으면 기존처럼 exe 옆에 둔 UnRAR.exe/7z.exe -> 설치된 WinRAR/7-Zip -> PATH의 도구 -> 윈도우 `tar.exe` 순으로 예비 시도합니다. 안내 문구도 새 상황에 맞게 바꿨습니다.
2. **왜 이 방법인가 (검토한 후보):** 파이썬만으로 RAR를 푸는 라이브러리는 없습니다(`rarfile`은 목차만 읽음). 제안받은 세 가지를 검토했으나 쓰지 않았습니다 - `DanielCaz/python-unrar`(MIT)는 라이브러리가 아니라 `patool`로 외부 도구를 부르는 작은 GUI 프로그램, PyPI `unrar`(GPL-3)는 DLL을 포함하지 않는 얇은 ctypes 껍데기이며 2019년 이후 갱신이 없고 GPL이 번질 수 있음, Aspose.ZIP은 상용. 대신 UnRAR 라이선스가 "RAR를 푸는 용도로 다른 소프트웨어에 포함해 배포"하는 것을 허용하므로 공식 UnRAR를 직접 포함했습니다. (정정: v0.6.0 때 "라이선스상 UnRAR만 풀 수 있다"고 쓴 설명은 부정확했습니다. 풀기 구현 자체는 허용되고, 금지되는 것은 RAR 압축을 만드는 프로그램을 만드는 것뿐입니다.)
3. **출처와 라이선스를 문서화:** `tools/README.md`(정체/버전, 소스 묶음의 SHA-256, 수정 내역, 만든 방법, 결과 exe의 SHA-256, UnRAR 라이선스 전문), `tools/UnRAR_license.txt`, `tools/unrar-mingw.patch`, `tools/build_unrar_windows.sh`(다시 만드는 방법), `THIRD_PARTY_NOTICES.md`(쓰는 외부 소프트웨어의 출처/라이선스와 검토했지만 쓰지 않은 것들). README에도 링크했습니다.
4. **이 `UnRAR.exe`는 RARLAB 사이트에서 받은 완성 exe가 아니라 직접 컴파일한 것입니다.** 이 개발 환경에서 rarlab.com에 접속할 수 없어서, 공식 UnRAR 7.00 소스(Ubuntu 패키지 `unrar-nonfree` 1:7.0.7-1build1의 원본 소스 묶음)를 mingw-w64로 윈도우용으로 교차 컴파일했습니다. 소스 수정은 `isnt.cpp`의 `bstr_t("...")` 두 곳을 `_bstr_t(L"...")`로 바꾼 한 줄뿐이며(MSVC 전용 라이브러리 없이 컴파일하기 위함) RAR 해제 동작과 무관합니다. 마음에 걸리면 RARLAB 공식 UnRAR.exe를 같은 이름으로 `tools/`에 덮어쓰면 됩니다.
5. **소스 zip 구성 변경:** 지금까지는 폴더 없이 평평했지만, 이번부터 `tools/` 폴더가 들어 있습니다(`build.bat`이 `tools\UnRAR.exe`를 참조하므로 폴더 구조를 유지해야 합니다).

**확인한 것:** Wine(윈도우 API 호환 계층)에서 이 `UnRAR.exe`로 RAR 5 일반/연속(solid) 압축 파일을 풀어 이미지 9장(한글·폴더 이름 포함)이 원본과 바이트까지 같고 이름 순서가 맞는 것을 확인했습니다(메모리/디스크 방식 모두). 암호 파일은 오류 코드 11로 거절됩니다. 프로그램이 번들 UnRAR를 가장 먼저 고르는 것, 기존 전체 테스트(분리 스모크, 드래그 막대, zip, 메모리/디스크, 키보드 이동, 툴바 줄바꿈, rar 읽기/앱 흐름)도 통과했습니다. 의존하는 DLL은 윈도우 기본 DLL뿐입니다.
**확인하지 못한 것:** (a) **진짜 Windows에서의 실행**과 (b) **PyInstaller로 만든 exe 안에서 번들된 UnRAR를 찾는 부분**(`_MEIPASS/tools`)은 이 환경에서 검증할 수 없습니다. 안 열리면 뜬 안내 창 글자를 알려 주세요. (c) RAR 4 형식으로 만든 이미지 샘플로는 풀기를 확인하지 못했습니다(RAR 5만 확인).

### 받는 방법
이 릴리스의 소스는 위 태그(`v0.7.0`)의 소스 코드입니다(GitHub가 자동으로 만드는 "Source code (zip)"). 압축을 풀고 폴더 구조를 그대로 둔 채 `build.bat`을 더블클릭하면 `dist\meltPDF.exe`가 만들어집니다(Python 3.9 이상 필요, 인터넷 필요). 자세한 사용법은 [README.md](https://github.com/yonggary-1/meltPDF/blob/v0.7.0/README.md), 전체 변경 이력은 [CHANGELOG.md](https://github.com/yonggary-1/meltPDF/blob/v0.7.0/CHANGELOG.md), 외부 소프트웨어 출처는 [THIRD_PARTY_NOTICES.md](https://github.com/yonggary-1/meltPDF/blob/v0.7.0/THIRD_PARTY_NOTICES.md)를 보세요.
