# meltPDF v0.17.0

**화면과 사용 편의 개선 묶음.** 새 아이콘, 불러오기 버튼 정리, 선택한 이미지만 내보내기, 이미지 복사, 이미지 용량 표시, 폴더 정렬 버그 수정.

1. **프로그램 아이콘 교체** (새 파일 `app_icon.py`, `tools/make_icon.py`, `assets/meltPDF.ico`, `assets/meltPDF.png`): 세로로 긴 그림 액자(가장자리가 물결처럼 굽은 장식 테두리) 안에 단순한 도장 모양. 한 가지 색(갈색), 투명 바탕. 외부 그림과 글꼴 없이 직접 그렸습니다. 창 아이콘(작은 창 포함)과 exe 아이콘(`build.bat`의 `--icon`)에 쓰입니다. 16~32px는 선을 굵게 한 모양을 따로 그립니다.
2. **불러오기 버튼 정리**: [이미지 추가], [기존 PDF 열기(수정)], [압축/책에서 이미지 추출]을 **[파일 열기/추가]** 하나로 합쳤습니다. 이미지, PDF, 압축/책 파일을 섞어 여러 개 고를 수 있고 끌어다 놓기와 같은 처리입니다(`file_loader.handle_paths`). 열 수 없는 형식은 건너뛰고 알립니다(끌어다 놓기도 이제 알림 - 이전에는 말없이 무시).
3. **[폴더 (이미지) 추가]** (이전 [폴더 추가], 새 파일 `folder_pick.py`): 작은 창에 [폴더 선택]과 "서브 폴더의 이미지 파일도 전부 추가" 체크 상자. 체크하면 하위 폴더의 이미지까지 모두 넣고(목록 이름은 "하위폴더/파일"), 안 하면 그 폴더 바로 안의 이미지만 넣습니다. 체크 상태는 기억합니다. 윈도우의 폴더 고르기 창에는 체크 상자를 넣을 수 없어 창을 하나 거치게 했습니다.
4. **버그 수정 - 폴더 이미지 순서**: 폴더의 이미지가 단순 글자 순(10이 2보다 앞)으로 들어오던 것을 zip과 같은 자연 정렬(1, 2, 10)로 고쳤습니다. 끌어다 놓은 폴더도 같습니다. 맥의 `._` 파일과 `__MACOSX` 폴더는 뺍니다.
5. **[선택된 이미지 내보내기]** (새 파일 `selected_export.py`): 목록에서 선택한 이미지를 묻지 않고 원본 파일 위치(처음 불러온 파일이 있는 폴더)에 바로 저장하고 "원본 파일 위치에 파일을 저장했습니다." 안내(저장한 폴더와 파일 이름도 표시). 새 폴더는 만들지 않습니다. 여러 개 선택이면 목록 순서대로 모두. 같은 이름의 파일이 있으면 덮어쓰지 않고 " (1)"을 붙입니다(파일을 새로 만들 때만 쓰는 방식이라 그 사이 생긴 파일도 덮어쓰지 않음). 이름과 내용 규칙은 전체 내보내기와 같습니다(`image_export.build_plan_into`). 기존 [이미지 내보내기]는 **[전체 이미지 내보내기]**로 이름을 바꿨습니다.
6. **이미지 보기 창의 [복사 (Ctrl+C)]** (새 파일 `image_clipboard.py`): [+] 옆의 버튼(겹친 종이 아이콘)이나 Ctrl+C로 보고 있는 이미지를 원래 크기 그대로 클립보드에 그림으로 넣습니다(웹 브라우저의 "이미지 복사"와 같음). 윈도우에서는 표준 그림 형식(CF_DIB, 투명한 부분은 흰 바탕)과 PNG(투명도 유지) 두 가지를 함께 넣습니다. 복사하면 버튼 옆에 "복사했습니다"가 2초 보입니다. PDF 쪽은 보기 창에 그린 그림(긴 변 2600px)이 들어갑니다.
7. **이미지 용량 표시** (새 파일 `size_info.py`): 하단 상태 표시줄에 "총 N페이지 (이미지 12.3MB)". 내보내기를 했을 때 이미지가 디스크를 차지하는 크기입니다. PDF 쪽이 섞여 있으면 어림값이라 "약"을 붙입니다.
8. **끌어다 놓기 안내 위치** (새 파일 `empty_hint.py`): 툴바 아래에 늘 떠 있던 안내 줄을 없애고, 목록이 비어 있을 때 작업 영역 가운데에 큰 글씨로 보여 줍니다("아래로" -> "여기로"). 하단과 겹치던 "썸네일을 눌러서 끌면..." 문장은 뺐습니다.
9. **하단 배치**: 내보내기 버튼이 셋이 되어 최소 폭(760px)에서 버튼이 잘려서, 메모리 미터를 버튼 줄에서 바로 윗줄(상태 문구 줄)의 오른쪽 끝으로 옮겼습니다. 최소 폭에서는 상태 문구 뒷부분이 잘려 보입니다.

**확인한 것:** Linux 가상 화면(Xvfb)에서 확인했습니다.
- 아이콘: 모든 크기(16~256px)에서 색이 정확히 한 가지이고 바탕이 투명함, 창 아이콘이 붙음.
- [파일 열기/추가]: 이미지 + PDF + cbt + djvu + txt를 한 번에 골라 이미지/쪽 10개가 고른 순서대로 들어오고 txt는 건너뜀 안내.
- [폴더 (이미지) 추가]: 체크 안 함은 바로 안의 이미지만 1, 2, 10 순서, 체크하면 하위 폴더까지(같은 폴더끼리 모여 자연 정렬), `__MACOSX`/`._` 제외, 체크 상태 기억.
- 이미지 용량: 이미지 항목은 [전체 이미지 내보내기]로 실제 저장된 용량과 바이트까지 일치. JPEG만 든 PDF(300쪽 포함)도 일치, 그 밖의 이미지가 든 PDF는 어림값(약간 차이).
- [선택된 이미지 내보내기]: 선택 없음 안내, 한 장 저장(원본과 바이트 일치), 같은 것 다시 저장하면 "10 (1).png", 여러 장, PDF 쪽(그 쪽의 원본 JPEG). 최소 폭(760px)에서 하단 버튼 셋이 모두 보임.
- 복사: 리눅스 클립보드(xclip)로 버튼과 Ctrl+C 모두 확인, 붙여 넣은 그림이 원본 투명 PNG와 픽셀까지 같음. 윈도우용 그림 형식(DIB) 머리 구조 확인.
- 빈 목록 안내: 비었을 때만 보이고, 들어오면 사라지고, 비우면 다시 나오며, 창 크기를 바꾸면 가운데로 옮겨짐.
- 회귀: zip/rar/7z/tar, epub/fb2/mobi/azw1/djvu, 서지 정보, PDF 이미지 꺼내기, 전체 이미지 내보내기, 잘린 zip 복구 시험이 모두 그대로 통과.

**확인하지 못한 것:**
- **Windows 클립보드 복사:** 윈도우용 코드(ctypes로 클립보드에 넣기)는 이 환경에서 실행해 보지 못했습니다(Wine에서 돌릴 윈도우용 파이썬을 받을 수 없었음). 그림판, 카카오톡, 워드에 붙여 넣기, 투명 PNG, 아주 큰 이미지(수천만 화소)를 Windows에서 확인해야 합니다.
- **Windows 화면:** 새 아이콘이 작업 표시줄/탐색기/창 제목줄에서 어떻게 보이는지, [폴더 (이미지) 추가] 창과 하단 배치가 Windows 글꼴에서 잘리지 않는지.
- 빈 목록 안내의 둘째 줄 형식 목록은 예전 그대로입니다(7z, epub, djvu 등 빠짐).

### 받는 방법
이 릴리스의 소스는 위 태그(`v0.17.0`)의 소스 코드입니다. 압축을 풀고 폴더 구조를 그대로 둔 채 `build.bat`을 더블클릭하면 `dist\meltPDF.exe`가 만들어집니다(Python 3.9 이상 필요, 인터넷 필요). 자세한 사용법은 README.md, 전체 변경 이력은 CHANGELOG.md, 외부 소프트웨어 출처는 THIRD_PARTY_NOTICES.md를 보세요.
