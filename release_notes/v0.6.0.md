# meltPDF v0.6.0

**rar/cbr 지원 추가, "파일명 순차 정렬" 버튼 이름을 "파일명 변경하기"로 변경, 툴바 줄바꿈 때 "보기:" 라벨이 떨어지는 문제 수정.**

1. **rar / cbr 이미지 추출** (새 파일 `archive_rar.py`, `rar_tool.py`): 툴바의 "압축/책에서 이미지 추출" 버튼이나 드래그앤드롭으로 rar/cbr을 넣으면 안의 이미지만 목록에 들어옵니다. 파일 종류는 확장자가 아니라 앞부분 서명(RAR 4/RAR 5)으로 판별하므로 이름이 `.cbz`인데 실제로는 rar인 파일도 열립니다.
   - **순서:** zip과 같은 이름 순(자연 정렬: `2`가 `10`보다 앞, 폴더 단위 비교, 대소문자 무시). 이미지는 재인코딩 없이 원본 바이트 그대로이며, PDF로 내보내도 같습니다(테스트에서 바이트 일치 확인).
   - **풀기는 외부 도구에 맡깁니다.** RAR 압축을 푸는 방법은 라이선스상 UnRAR 계열만 쓸 수 있어서 직접 구현하지 않고, 컴퓨터에 있는 도구를 찾아 씁니다. 순서: ① `meltPDF.exe`와 같은 폴더(또는 `tools` 폴더)의 `UnRAR.exe` ② 설치된 WinRAR/7-Zip ③ PATH의 unrar, 7z, unar, bsdtar ④ 윈도우 기본 `tar.exe`. 한 도구가 실패하면 다음 도구로 자동 재시도하고, 모두 없거나 실패하면 설치 방법(7-Zip 설치 또는 UnRAR.exe 복사)을 안내합니다. 목차(이름/크기/암호 여부)는 `rarfile` 라이브러리가 파이썬으로 읽으므로 이 부분은 도구가 필요 없습니다(`requirements.txt`에 `rarfile` 추가).
   - **한 번에 전부 풀고 나서 이미지를 고릅니다.** 파일을 하나씩 풀면 연속(solid) 압축에서는 앞의 파일들을 매번 다시 풀어서 극도로 느려지기 때문입니다. 그래서 RAR는 "메모리" 방식이어도 풀리는 동안만 디스크 임시 폴더를 쓰고(끝나면 지움), 이미지 이외의 파일도 같이 풀립니다. 진행 표시줄은 풀린 파일 수로 갱신됩니다.
   - **거절하는 것(이유를 알려 줌):** 암호가 걸린 rar(내용 암호, 목차 암호 모두), 서명만 rar이고 내용이 읽히지 않는 손상 파일, 항목 1GB/전체 16GB 초과(zip과 같은 한도), 여러 조각으로 나뉜 rar의 중간 조각.
2. **"파일명 순차 정렬" 버튼 → "파일명 변경하기"** (버튼과 창 제목). 동작은 그대로입니다.
3. **툴바 줄바꿈 수정:** "보기:" 라벨과 타일형/목록형 라디오 버튼을 한 덩어리로 묶어서, 창이 좁아 줄이 넘칠 때 라벨이 따로 떨어지지 않고 통째로 다음 줄로 내려갑니다. (창 폭 760~1270px을 10px씩 바꿔 가며 확인)

**확인한 것:** 이 환경(리눅스)에서 `rar`로 만든 RAR 5 파일(일반/연속(solid)/암호/목차 암호/한글·폴더 이름 포함)을 UnRAR, bsdtar, unar로 풀어 이름 순서와 바이트 일치를 확인했습니다(메모리/디스크 양쪽). UnRAR이 없다고 가정했을 때 다음 도구로 넘어가는 것, 도구가 하나도 없을 때의 안내, 임시 폴더가 남지 않는 것, 앱에서 rar+zip+이미지를 한꺼번에 떨어뜨렸을 때 넣은 순서 유지, 암호 rar의 경고창, 기존 전체 테스트(분리 스모크, 드래그 막대, zip, 메모리/디스크, 키보드 이동)도 통과했습니다.
**확인하지 못한 것:** (a) **실제 Windows에서 rar/cbr이 열리는지**(7-Zip/WinRAR/UnRAR.exe/윈도우 tar.exe 호출과 창 없는 프로그램에서의 동작) - 이 환경에서는 Windows 도구를 쓸 수 없습니다. (b) 7-Zip: 여기 리눅스 7-Zip은 RAR 해제 기능이 빠진 빌드라 확인하지 못했습니다(Windows용 공식 7-Zip은 RAR 5를 풉니다). (c) RAR 4 형식으로 만든 이미지 샘플은 만들 수 없어서 서명 인식과 목차 읽기만 확인했고 실제 풀기는 확인하지 못했습니다. (d) 윈도우 `tar.exe`가 rar를 풀 수 있는지는 윈도우 버전에 따라 다를 수 있습니다. 풀리지 않는 환경이면 7-Zip을 설치하면 됩니다.
