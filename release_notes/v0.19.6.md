# meltPDF v0.19.6

**수정: 깨진 이미지 검출 누락(동시 처리 경합), 못 읽는 파일도 목록에 넣기, 머리 부분 복구, PDF 빈 쪽, [깨진 이미지 N장] 버튼.**

1. **깨진 이미지가 손상 표시 없이 통과하던 버그 (v0.18.0부터)** (새 파일 `decode_guard.py`):
   - 원인: 깨진 이미지를 "읽을 수 있는 데까지" 읽는 동안 이미지 라이브러리(Pillow) 전체 설정이 켜져서, 그 순간 다른 스레드가 읽던 깨진 이미지가 오류 없이 통과했습니다.
   - 시험(300장 중 끝이 잘린 100장, 8스레드): 손상 표시 60~67장, 통과 33~40장(PNG, JPEG 모두). 한 장씩 처리하면 100장 모두 잡혔습니다.
   - 수정: 깨진 데까지 읽기는 혼자, 보통 읽기는 여럿이 동시에 하도록 잠금을 둡니다.
2. **전혀 못 읽는 파일도 목록에 넣기** (사용자 요청 - 검출은 필수, `damaged_image.unreadable_item`):
   - 대상: 빈 파일, 머리가 깨진 파일, 이미지가 아닌 파일 등. 빼지 않고 빈 상자에 X자 썸네일 + 빨간 테두리로 넣습니다.
   - 목록형에는 "크기 모름 | 읽지 못함: (이유)", 불러온 뒤 "읽지 못한 이미지 N개" 경고 창(이름과 이유).
   - 압축/책 파일 안에서 꺼내지도 못한 이미지도 X 표시로 원래 순서 자리에 넣습니다(zip, cbz, epub, tar, 7z, rar, fb2, djvu의 못 푼 쪽). azw1(Topaz)의 이미지가 아닌 기록은 예전처럼 뺍니다.
   - 보기 창은 X 상자를 크게 보여 주고, 복사는 막습니다. 이미지 내보내기는 원본 파일을 그대로 저장합니다.
3. **머리 부분 복구** (새 파일 `header_repair.py`, `damaged_image.recover`):
   - 보통 읽기와 깨진 데까지 읽기가 모두 실패한 PNG/JPEG는 머리 부분을 표준값으로 다시 써서 다시 읽습니다. PNG는 서명과 IHDR(표준 위치, 검사값으로 확인), JPEG는 시작 표시와 크기 표시(SOF)를 봅니다.
   - 다 풀리면 그림 전체를, 일부만 풀리면 깨진 이미지로 넣습니다(빨간 테두리 유지, 목록형 "손상됨(머리 부분 복구)", 내보내기에는 복구한 데이터).
   - 그림은 못 풀어도 크기를 찾으면 X 표시 항목에 적습니다(예: "640x480px(머리에서 찾은 크기)").
4. **PDF에 빈 쪽** (`pdf_core._fit_blank_pages`): 못 읽는 이미지 자리에 빈 쪽을 넣어 쪽 수와 순서를 맞춥니다.
   - 쪽 크기: 머리에서 찾은 크기(96dpi 기준). 못 찾았으면 바로 앞 쪽과 같게(맨 앞이면 바로 뒤 쪽, 회전도 따름).
   - 끝난 뒤 "읽지 못한 이미지 N장은 그 자리에 빈 쪽으로 넣었습니다" + 이름 목록. 전부 못 읽는 이미지면 내보내지 않습니다.
5. **[깨진 이미지 N장] 버튼** (새 파일 `damaged_nav.py`): 하단 [전체 삭제]와 [선택된 이미지 내보내기] 사이.
   - N은 빨간 테두리 이미지 수이고, 불러오거나 지울 때 바로 바뀝니다. 옅은 빨강 바탕이고, 0장이면 회색으로 잠깁니다.
   - 누를 때마다 목록 맨 앞부터 다음 깨진 이미지를 선택해 화면 가운데로 스크롤합니다. 끝 다음은 처음으로 돌아가고, 상태 줄에 "깨진 이미지 2/5: 이름 (종류)"를 보여 줍니다.

**확인한 것** (리눅스와 Wine의 윈도우용 파이썬):
- 동시 처리 시험: 리눅스 5회와 Wine 3회 모두 100/100, 잘못 판정 0. 깨진 이미지가 없을 때 속도는 JPEG 16ms/장, PNG 125ms/장으로 변화 없음.
- 섞은 시험 파일(폴더와 같은 내용의 cbz):
  - 빈 파일/HTML/무작위 데이터: X 표시, 이유 표시, 앞 쪽 크기의 빈 쪽.
  - 서명이 깨진 PNG(640x480), 앞 16바이트가 깨진 PNG(300x400), 시작 표시가 깨진 JPEG(500x700): 그림 전체 복구.
  - 그림 데이터까지 깨진 PNG: 크기(640x480)만 찾아 480x360pt 빈 쪽.
  - 끝이 잘린 JPEG: 일부 표시.
- 맨 앞이 못 읽는 이미지일 때, 그 이미지를 표지로 지정해 맨 앞으로 옮겼을 때도 빈 쪽은 바로 뒤 쪽 크기. 이미지 내보내기 결과는 원본과 바이트까지 같음. djvu의 못 푼 쪽이 쪽 순서 자리에 빈 쪽으로 들어감.
- 버튼: 1,010장(깨진 8장)을 불러오는 동안 숫자 갱신, 8번 눌러 차례로 모두 화면 안에 보임, 9번째는 처음으로, 지우면 줄고 전체 삭제면 0장/잠김. 창 최소 폭 다시 계산.
- 기존 회귀 시험 통과. 못 푼 djvu 쪽이 이제 빠지지 않고 들어가므로, 쪽 수를 보던 시험 두 개는 새 동작에 맞게 고쳤습니다.

**확인하지 못한 것:**
- 실제로 깨진 파일에서 머리 부분이 얼마나 복구되는지(손상 위치가 파일마다 다름. 시험은 직접 망가뜨린 파일로만).
- 실제 윈도우에서 버튼의 색과 모양.

### 받는 방법
이 릴리스의 소스는 위 태그(`v0.19.6`)의 소스 코드입니다. 압축을 풀고 폴더 구조를 그대로 둔 채 `build.bat`을 더블클릭하면 `dist\meltPDF.exe`가 만들어집니다(Python 3.9 이상 필요, 인터넷 필요). 자세한 사용법은 README.md, 전체 변경 이력은 CHANGELOG.md, 외부 소프트웨어 출처는 THIRD_PARTY_NOTICES.md를 보세요.
